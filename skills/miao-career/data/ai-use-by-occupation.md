# 各职业实际用 AI 的比例（只在第 2 步要用 AI 系数时读）

- **日期**：2026-10-27 查阅
- **样本**：美国全国代表性调查 RPS（*What Work Does Generative AI Do?*，Bick、Blandin、Deming 等），2025-08 到 2026-05 四波合并，近 14,000 个在职观察
- **口径**：“为工作用过生成式 AI”，不是每天用
- **局限**：细职业常只有几十人，几个百分点的差距不能排高低；不能叫“现在的比例”
- **出处**：https://sites.google.com/view/covid-rps/data 、https://www.stlouisfed.org/on-the-economy/2026/sep/what-work-does-generative-ai-do

全体劳动者为工作使用约 45%（2026-05）。

| 职业 | 比例 | 样本数 |
|---|---:|---:|
| 公关专员 | 80.4% | 31 |
| 市场研究分析师与营销专员 | 78.7% | 31 |
| 平面设计师 | 75.4% | 31 |
| 一般与运营经理 | 70.7% | 214 |
| 管理分析师 | 61.8% | 125 |
| 销售经理 | 57.9% | 141 |
| 作家与编辑合并 | 48.9% | 74 |
| 作家与作者 | 48.5% | 51 |
| 批发制造销售代表 | 45.5% | 51 |
| 网页和数字界面设计师 | 43.3% | 29 |
| 其他业务运营专员 | 41.7% | 45 |
| 服务销售代表 | 34.1% | 29 |
| 运筹分析师 | 33.0% | 22 |
| 客服代表 | 30.1% | 177 |

**没查到独立比例**：产品经理、产品运营、客户成功、社媒专员、全体 UX / 产品设计、通用数据分析师。广告经理、编辑、数据科学家样本不足，原表不发布。没有直接数据时，可以用邻近职业，但要写明“邻近”。

## 分母不能混

| 数字的分母 | 能回答 | 不能当作 |
|---|---|---|
| 某职业的在职受访者 | 这类工作多少人用 AI | 每天使用的比例 |
| 某行业的企业（Census BTOS） | 多少企业有一处业务在用 | 多少员工在用 |
| AI 产品的对话记录（Anthropic、OpenAI 的报告） | 已有用户拿 AI 做什么 | 从业者使用率 |

其他总体参考：Pew 2026-02 调查，38% 的就业成年人用聊天机器人做过工作任务（https://www.pewresearch.org/internet/2026/06/17/americans-and-ai-2026-chatbots-smart-devices-and-views-on-impact/）；Gallup 2026-08，雇员 16% 每天、32% 每周几次以上用 AI（https://www.gallup.com/699797/indicator-artificial-intelligence.aspx）。范围和时间都不同，不能平均。

招聘原文很少写 AI，所以不能只靠招聘原文判断一行用不用 AI。
