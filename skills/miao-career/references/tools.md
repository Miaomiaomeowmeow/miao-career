# 连工具（开场第 5 步读）

一个一个问：要不要连这个？每个先说清能干嘛、跳过会少什么。全都能跳过。账号由用户本人登录，你不输密码。下面的步骤是 2026-11 按官方文档写的，没有在每种账号上试过；界面对不上时，按用户看到的为准。

用户说全部跳过，就记下跳过，不追问客户端。要连至少一个时，才问用的是哪种：Codex 桌面版、Codex 命令行、IDE 扩展，还是 Claude Code。

## Gmail

- **能干嘛**：定期搜校友活动、招聘会、就业中心通知、和联系人的往来（第 7 步）。
- **跳过会少什么**：我给搜索语句，用户自己在 Gmail 里搜，把结果贴给我。
- **怎么连（Codex）**：Plugins → 找 Gmail → 点加号安装 → 连账户、看权限 → 新开一个聊天。命令行用 `/plugins`，装完新开 session。IDE 扩展当前不支持插件。出处：https://learn.chatgpt.com/docs/plugins 、https://openai.com/business/plugins/gmail/
- 不是所有账户都一定能连，官方没有写清最低套餐。连不上就跳过。
- **其他 AI**：如果有 Gmail 连接器就用，没有就走“跳过”的办法。
- 只读和搜索。Gmail 插件带写入能力，但本 skill 不用它发信。

## LinkedIn 插件

- **能干嘛**：按姓名和公司查人，看职位、公司、地点和资料链接（第 7 步）。这是官方插件，开发者是 LinkedIn。
- **做不到**：官方没说能读好友名单、批量导出、加好友或发私信。别指望。
- **跳过会少什么**：用户自己在 LinkedIn 搜人，把名字和链接贴给我。
- **怎么连（Codex）**：同上，在 Plugins 里找 LinkedIn。出处：https://openai.com/business/plugins/linkedin/

## 浏览器扩展（连已登录的浏览器）

- **能干嘛**：第 6 步用 Handshake 网页版、LinkedIn 网页版改资料时，我在你已登录的页面上一项项改，每项先给你看原文。
- **跳过会少什么**：我写好稿，你自己贴。
- **怎么连（Codex 桌面版）**：更新桌面应用 → Settings > Computer Use → 选浏览器（Chrome、Edge、Brave、Opera、Vivaldi）→ Install → 在扩展商店装 ChatGPT 扩展，看权限 → 回来确认显示 Manage → 新建聊天，用 `@Chrome` 这样选浏览器或标签页。出处：https://learn.chatgpt.com/docs/chrome-extension
- **权限**：网站权限选“一次允许”或“只允许这个站”，不要选所有网站。
- **内置浏览器**：桌面版的 `@Browser` 不用安装，但它和你日常的浏览器分开，没有你的登录状态。命令行和 IDE 扩展没有它。
- **其他 AI**：如果你的 AI 有能连已登录浏览器的扩展，用法一样。
- 能操作网站，不等于网站允许自动化。规矩看第 6、7 步。

## Handshake

目前没查到官方插件（2026-11，没查到不等于绝对没有）。要 AI 帮忙就走浏览器扩展 + 网页版，见第 6 步。

## 定时任务

- **能干嘛**：按用户定的频率提醒看跟踪表、搜 Gmail。
- **怎么设（Codex 桌面版）**：在聊天里说要做什么、什么时候做、回原聊天还是新开聊天，再到侧边栏 Scheduled 管理。需要读本地文件的任务要求电脑开着、桌面应用开着、文件夹还在。出处：https://learn.chatgpt.com/docs/automations
- **命令行版没有这个**：改成每次打开时提醒。设置文件里记上次看的日期，到时间就提一句。
- **跳过会少什么**：什么都不少，只是要记得打开。

## 做完

把每个工具连了没写进设置文件的“工具”表，新开聊天后才能用的要提醒用户。
