# 第 5 步 简历

## 开头这样讲

- **做什么**：把你的真事写得最有力，按第 2 步的结果分版。
- **我们的标准**：美化可以，编造不写。每个数字你都讲得出来历。
- **费不费额度**：很少，不搜索。用好一点的模型（判断和写作）。查招聘原文对关键词时才费一点。
- **要不要做**：问用户有没有现成简历（贴或给文件）、要改几版、用什么格式。

## 界线

| 可以 | 不可以 |
|---|---|
| 同一个数字换更好的说法：30 → 90 写成 3× | 编没发生的数字，把 3× 写成 6× |
| 加真实的条件：零预算、一周内、独自一人 | 抢别人的功劳 |
| 强动词，讲成果不讲任务 | 改职位名、改日期、加没做过的公司 |
| 只挑最好的几件写 | 写自己讲不出细节的事 |
| 写峰值时加 up to | 把峰值写成平均值 |

被问为什么不编时再讲，别说教：公司会背调、打电话问前老板；面试官会顺着数字往下问；一份自报调查里，撒谎被发现的人 41% 的 offer 被收回（https://www.resumebuilder.com/1-in-3-americans-admit-to-lying-on-resume/）；留学生丢了 offer，OPT 的期限照样在走。

## 改写工具箱

1. 有原始证据（知道起点和终点）才把小数字换成倍数或百分比，基数小时用倍数。讲不出分母的保留原数字。
2. 峰值加 up to。
3. 加让它更难的条件：with zero budget、within one week、as the only analyst、in my first month。
4. XYZ 公式：Accomplished X as measured by Y, by doing Z。（https://harbert.auburn.edu/blogs/school-of-accountancy/better-resume-formula.html）
5. 强动词开头：Built、Launched、Grew、Designed、Led、Owned、Turned。自己负责的不写 Helped；真的只是帮忙就写 Supported、Contributed to。
6. 零散工具串成一条流程。
7. 没有结果数字时写规模、频率、速度：analyzed 2,000 survey responses；weekly；in 3 days；for 5 clients。
8. 公司小、没人认识：写清它做什么。
9. 职位名不改，可以在后面用逗号补一句实际干的。
10. 一条一件事，两行以内；最重要的放每段第一条。

## 先问清再写

一段一段问：你具体做了哪部分？别人做了哪部分？数字哪来的？不问清楚就写，最容易把别人的功劳写成用户的。

**数字分三种**：做了多少、计划覆盖多少、实际结果如何。公司总用户数、预计传播人数不能当个人成果。

**没有业务数字时**：真实的测试人数、轮次、上线状态、分工、反馈都算证据。没测过别人就不写“测过”，面试会问几个人、说了什么、改了什么。真要写，找 3 个人各试 10 分钟就有了。

**框架**：对象或问题 → 本人动作 → 交付物 → 可证实的规模或结果。不是每条都要百分比。【推断，看真实新人简历总结的】

**实习**写到本人交付，别止于公司名。

**用了 AI**：写清 AI 帮了什么，不把工具做的写成自己独立实现。面试时好讲。

## 按岗位分版

- 版数和类型来自第 2 步。
- 每版的经历栏一样，只换顶上的身份、项目顺序、讲哪个点、配哪个数字。
- 写之前读这类岗位的招聘原文（第 4 步的 CSV 里挑），有几份用几份，最多 5 份，抓反复出现的技能和说法。没有就按用户说的方向写，并告诉用户这是没对照招聘原文的版本。
- 告诉 AI 目标岗位，围绕方向重写，同时核证据：改关键词补不上缺的经历。缺的就告诉用户，别写。
- 要写投递信的话：我们没有专门的方法。按岗位挑一两件真事讲，不编。

## 美国规矩和格式

- 应届一页，教育放经历前面；有相关工作经验的，经历放前面，页数看经历多少（这部分主要按新人写的，【推断】）。Letter 纸（不是 A4）；单栏，方便招聘系统读；不放照片、年龄、婚育。
- 顺序：名字和联系方式 → 一句定位（转方向时很有用）→ 教育（应届放前面）→ 经历（倒序）→ 项目 → 技能。样本里教育和经历谁先没有单一答案。
- 不写 GRE、雅思、本科课程列表；外国的证书和比赛只留最亮的一两个。
- 兴趣爱好压成一行；核对公司的正式英文名。
- 技能别写星级。
- 默认黑白（可改）。项目有链接就放在项目旁边，只放一个主页链接，招聘方可能以为是编的。
- 放不下先问删什么，不自己删。

可以用 OpenResume（https://www.open-resume.com）：免费、不注册、数据只在自己浏览器里；它的 Parser 能看招聘系统大概会怎么读你的 PDF。它不一定准，只当参考。

**ATS**：我们没有专门的关键词优化方法。只有两条：单栏好读；用招聘原文里的真实说法。不要承诺“能过 ATS”。

## 改完自查（交给用户前逐条查）

- [ ] 每条都是做成了什么，不是负责什么
- [ ] 倍数和百分比都有原始证据，讲不出分母的保留了原数字
- [ ] 每个数字用户都讲得出来历
- [ ] 没有把别人的功劳写成用户的
- [ ] 一页，没有错字，日期格式一致
- [ ] 能导出就导出 PDF，看是不是一页。不能导出就交可编辑文件，让用户自己导出后看，不要声称查过
- [ ] 对照用户说过的话逐条清点，点名要放的都在
- [ ] 读起来像真人写的：删掉 leverage、spearhead、passionate 这种词和“不仅……而且……”的句式

## 做完

草稿可以直接存。先给原文，用户点头才算定稿。存进用户的 `简历/`，文件名写版本和日期。在设置文件记“简历分几版”。
